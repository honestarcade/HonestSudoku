# ArtSource

Rendered artwork that is committed but not bundled into the app.

- `store/`: Play Store listing art. `icon-512.png` is rendered by
  `tools/render_icons.sh` from `assets/brand/icon-tile.svg` (#54); the
  feature graphic and screenshots arrive with #57.
- `audit/`: screenshots taken to check a story by eye (for example
  `audit/icon/` for the launcher icon, #54).
