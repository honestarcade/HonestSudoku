# Honest Sudoku

A Sudoku game built with Flutter, targeting mobile, desktop, and web.

The project is freshly initialized; gameplay and features are planned and tracked as GitHub Issues.

## Build and run

```sh
flutter pub get
flutter run            # pick a connected device or simulator
flutter run -d chrome  # web
```

## Test and lint

```sh
dart analyze
dart format --set-exit-if-changed .
flutter test
```
