# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub's
[private vulnerability reporting](https://github.com/honestarcade/HonestSudoku/security/advisories/new).
Do not open a public issue: a public reproduction is a working exploit handed to everyone.

This is a small, volunteer-maintained project. Reports are read, but there is no guaranteed
response time. Confirmed issues are fixed as capacity allows and credited in the release notes
unless you ask otherwise.

## Findings from our own audits

Security findings discovered by the project's own audits are tracked as public issues under the
`security` label, with a `sev:*` label for severity, so anyone using the app can assess risk.
